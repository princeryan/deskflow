Detailed Description

Key state for the uinput (headless evdev) backend.

The keymap logic is intentionally identical to EiKeyState: it builds a deskflow KeyMap from a libxkbcommon keymap and stores the evdev keycode (X keycode - 8) as KeyItem::m_button, so the value handed to UInputScreen::fakeKey() is already a raw evdev keycode.

◆ setLockLeds()

bool deskflow::UInputKeyState::setLockLeds ( KeyModifierMask mask)

Adopt the lock state the session is actually in.

We inject through a kernel device and cannot read the compositor's keyboard state, so our xkb shadow is a guess that drifts the moment anything else toggles a lock – or the moment we are started while one is already on. The session broadcasts the truth as LED state to every keyboard device, so UInputScreen feeds it back here. mask carries KeyModifierCapsLock, KeyModifierNumLock and KeyModifierScrollLock. Returns true if this changed what we believed.
